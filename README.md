# TetorisuKU
건국대학교 객체지향프로그래밍 프로젝트

## 실행

Visual Studio에서 `Tetris.slnx`를 열고 `Tetris`를 시작 프로젝트로 지정한다. 메인 메뉴에서 스토리 모드 또는 일반 모드를 선택한다.

- **1인 수사**에서 방향키 좌우로 시작 사건을 1~5단계 중 고른다. 추격 점수가 목표에 도달하면 체포하고, 0점이나 보드 넘침은 사건 실패다. 어느 단계에서 출발하든 마지막 사건을 해결하면 같은 진급식으로 마무리한다.
- **2인 추격전**은 한 키보드를 사용한다. 1P 경찰은 WASD, Q, Space, 왼쪽 Shift를, 2P 도둑은 방향키, /, 오른쪽 Shift, Enter를 쓴다. 1500점에서 시작해 3000점이면 체포, 0점이면 도주다.
- **일반 싱글**은 시작 난이도 1~8을 고를 수 있다. 8단계에서는 게임 오버까지 그 판의 누적 점수를 겨룬다.

## 기획 기록

- **2026-11-26** — 경범죄, 소매치기, 사기, 강도, 살인 사건의 5단계 캠페인을 기획했다. 사건을 해결할수록 더 어려운 수사를 맡고, 마지막 사건을 해결하면 정식 진급한다. 2인에서는 서로의 줄 삭제 점수가 추격 거리를 움직인다.
- **2026-11-27 · 강의 기준 검토** — 수업의 포함과 다형성 예제에 따라 스테이지가 기믹 객체를 소유한다. 2~4단계의 기믹을 마지막 사건에서 같은 인터페이스로 재사용한다.
- **2026-11-27 · 시연용 밸런스** — 과제 시연과 반복 테스트가 쉽도록 1인 사건마다 체포 목표를 시작 점수보다 **300점** 높게 설정했다. 한 사건을 **3분 이내**에 끝내는 것을 플레이 테스트 기준으로 삼았다. 블록이 보드에 고정될 때 발동 확률을 확인하고, 마지막 사건에서는 성공 시 기믹 하나를 가중치로 추첨한다.
- **2026-11-27 · 이야기와 화면** — 사건명으로 용의자를 표시하고, 사건마다 다른 도트 초상화와 추격 아이콘을 사용한다. 발동 확률은 0%, 14%, 17%, 10%, 20%다. 마지막 용의자는 앞선 수법을 모방하고, 공포 층은 예고 대사 약 0.7초 뒤에 올라온다.

## 팀 확장 지점

- 스테이지는 기믹 객체를 소유하고 발동 시점을 정한다. `StoryGimmick`의 파생 클래스는 효과와 대사 신호를 반환하고, `StoryPresentation`이 사건별 대사와 도트를 고른다. 모방 대사를 추가할 때 기존 효과를 재사용한다.
- 포털과 블록 저장은 `Board::wrapX`, `Board::setBorderless`, `Player::hold`에서 확장할 수 있다. 스토리의 홀드 도난도 `Player`의 보관 블록을 비우는 공개 함수로 처리한다.
- 아이템은 `IItem`, `Player::addItem`, `Player::useFirstItem`을 사용하고, 줄 삭제로 발동하는 효과는 `IBlockEffect`를 이용할 수 있다. 지급 조건, 사용 키 연결, 인벤토리 화면, 사건을 넘길 때 소지품 처리 방식은 아이템 구현에서 정한다. `Player::reset`은 현재 소지품을 초기화한다.
